# 🐝 SwarmPoll

SwarmPoll is a free, open-source prediction tool inspired by the honeybee "waggle dance". It uses a confidence-weighted consensus algorithm to reveal the "true" hidden consensus of a group, ignoring loud but unconfident voices.

## Features
- **Unlimited Scale:** Simulates up to 1,000,000 voters using Monte Carlo sampling.
- **Confidence Weighting:** Users vote with a confidence score, and the algorithm shifts the consensus toward the experts.
- **The "Aha!" Insight:** Highlights when the Swarm Consensus flips the traditional Raw Vote.

## How to use
Simply open `index.html` in any web browser. No backend, database, or installation required.
